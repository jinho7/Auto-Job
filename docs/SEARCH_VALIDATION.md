# 개인 자료 기반 공고 검색 검증

2026-09-17 KST. Auto-Job의 검색 키워드를 선택 사항으로 바꾸고, 공고 수집 전에 사용자별 자료 분석을 추가했습니다.

## 동작

- CLI와 설정 화면 모두 현재 사용자의 프로필과 `stories.folders`를 읽어 검색 계획을 만듭니다. 연락처만 있는 프로필은 검색 근거로 보지 않습니다.
- md/markdown/txt와 로컬 `pdftotext`로 추출한 PDF 내용을 모든 AI 연결에 같은 방식으로 전달합니다. 긴 내용은 앞부분만 자르지 않고 여러 번에 나눠 분석합니다. 파일 및 폴더 설명도 출처로 구별합니다.
- AI가 추출한 인용이 실제 입력 자료에 있는지 확인합니다. 확인된 근거 ID를 인용한 직무만 검색 방향으로 채택합니다. 문서의 명령을 실행하지 않도록 지시하고 분석 에이전트에 도구를 주지 않습니다.
- 자동 검색어는 최대 12개이며 직접 입력한 추가 검색어와 합쳐 수집기에 전달합니다. 저장된 키워드와 사이트별 직무 분류, 기업 구분 등 필터는 유지합니다.
- 수집 결과에 실제 검색어, 선정 이유, 근거와 미처리 자료를 표시합니다. 프로필 이름·연락처·주소·등록번호는 검색 문맥에서 제외합니다. 사용자가 연결한 파일 내용에는 별도 개인정보 제거를 적용하지 않으며 선택한 AI로 전달됩니다.
- 개인 자료가 없고 수동 조건만 있으면 수동 검색임을 알립니다. 개인 자료 분석 실패를 고정 직무나 수동 검색으로 조용히 대체하지 않습니다.
- 읽기 제한은 파일당 8MB, 폴더당 400개·깊이 6단계이며 누락을 경고합니다. 전체 입력 120만 자 또는 추출 근거 20만 자를 넘으면 범위를 줄이도록 안내하고 검색을 중단합니다.
- 개인 자료가 들어 있는 AI 임시 작업 폴더는 성공·실패 후 삭제합니다. 실행 결과 리포트는 `data/runs/`에 권한 600으로 저장합니다.
